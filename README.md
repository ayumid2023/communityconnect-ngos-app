# CommunityConnect – NGO Management Platform

A unified web-based NGO management platform with embeddable widgets for donor management, volunteer coordination, fundraising, and impact tracking.

## Features

- 🎯 **Donor Management**: Track donors, donations, and communication history
- 💳 **Online Donations**: Secure payment processing via Stripe
- 👥 **Volunteer Management**: Recruit, assign, and track volunteers
- 📊 **Impact Dashboard**: Show donors the real-world impact of their contributions
- 🔌 **Embeddable Widgets**: Add donation and volunteer sign-up forms to any website
- 🛡️ **White-Label**: Fully customizable branding for NGOs

## Tech Stack

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express + MongoDB
- **Payment**: Stripe
- **CI/CD**: GitHub Actions
